配点 : 100 点

問題文

整数 A, B, C が与えられます。
A^2 + B^2 < C^2 かを判定してください。

制約

  • 0 \le A \le 1000
  • 0 \le B \le 1000
  • 0 \le C \le 1000
  • A, B, C は整数である

入力

入力は以下の形式で標準入力から与えられる。

A B C

出力

A^2 + B^2 < C^2 なら Yes を、そうでないなら No を出力せよ。

入力例 1

2 2 4

出力例 1

Yes

A^2 + B^2 = 2^2 + 2^2 = 8 、C^2 = 4^2 = 16 より A^2 + B^2 < C^2 なので Yes を出力します。

入力例 2

10 10 10

出力例 2

No

A^2 + B^2 = 200 、C^2 = 100 なので A^2 + B^2 < C^2 ではありません。

入力例 3

3 4 5

出力例 3

No
