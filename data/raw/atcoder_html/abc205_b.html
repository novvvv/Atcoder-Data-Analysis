配点 : 200 点

問題文

1 以上 N 以下の整数からなる長さ N の数列 A = (A_1, A_2, \dots, A_N) が与えられます。

A が (1, 2, \dots, N) の並び替えによって得られるかどうか判定してください。

制約

  • 1 \leq N \leq 10^3
  • 1 \leq A_i \leq N
  • 入力は全て整数である。

入力

入力は以下の形式で標準入力から与えられる。

N
A_1 A_2 \ldots A_N

出力

A が (1, 2, \dots, N) の並び替えによって得られるなら Yes、そうでないなら No と出力せよ。
