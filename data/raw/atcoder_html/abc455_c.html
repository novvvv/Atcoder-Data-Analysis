配点 : 300 点

問題文

整数列 A = (A_1, A_2, \ldots, A_N) が与えられます。

以下の操作をちょうど K 回行った後の A の各要素の和として考えられる最小値を求めてください。

  • 整数 x を選ぶ。A_i = x なる各 i について A_i の値を 0 に置き換える。

制約

  • 1 \leq K \leq N \leq 3 \times 10^5
  • 1 \leq A_i \leq 10^9
  • 入力される値はすべて整数

入力

入力は以下の形式で標準入力から与えられる。

N K
A_1 A_2 \ldots A_N

出力

答えを出力せよ。
